Task 1.2 — Scoping and Shadowing (JavaScript)

6 points
~10 min

Consider the following JavaScript code. For each labeled console.log, determine what value is printed.

Recall: var is function-scoped and hoisted; let is block-scoped and not hoisted.

function example() {
    var x = 1;
    let y = 2;
    console.log(x);  // Line A
    {
        var x = 3;   // re-declares the same function-scoped `x`
        let y = 4;   // new block-scoped `y`, shadows outer `y`
        console.log(x);  // Line B
        console.log(y);  // Line C
    }
    // inner block ended; var x = 3 persists; let y = 4 is gone
    console.log(x);  // Line D
    console.log(y);  // Line E
    var x = 5;
    console.log(x);  // Line F
}

program PointerExample;
var
  a, b, c: integer;
  p, q: ^integer;
begin
  a := 2;
  b := 3;
  c := 5;
  p := @a;          { p points to a }
  q := @b;          { q points to b }
  p^ := p^ + c;     { a := a + c = 2 + 5 }

  writeln(q^);      { Line C }

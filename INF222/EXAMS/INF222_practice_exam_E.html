Task 1.2 — Scoping and Hoisting (JavaScript)

6 points
~10 min

Consider the following JavaScript code. For each labeled console.log, determine what value is printed.

Recall: var is function-scoped and hoisted (declaration moves to top, value stays); let is block-scoped and not hoisted.

function process() {
    console.log(typeof count); // Line A
    var count = 5;
    let flag = true;

    if (count > 0) {
        var count = 10;        // re-declares the same function-scoped count
        let flag = false;      // new block-scoped flag, shadows outer flag
        var status = "ok";     // new function-scoped var
        console.log(count);    // Line B
        console.log(flag);     // Line C
    }

    console.log(count);        // Line D
    console.log(flag);         // Line E
    console.log(status);       // Line F
}

Task 1.3 — Pointers (Pascal)

4.5 points
~10 min

Consider the following Pascal program. What does each writeln statement print?

program PointerDemo;
var
  x, y, z: integer;
  p, q: ^integer;
begin
  x := 4;
  y := 6;
  z := 2;
  p := @x;           { p points to x }
  q := @y;           { q points to y }
  p^ := p^ * z;      { x := x * z }
  q^ := q^ + p^;     { y := y + x  }
  p := q;            { p now points to y }
  p^ := p^ - z;      { modifies y via p }
  writeln(x);        { Line A }
  writeln(y);        { Line B }
  writeln(p^);       { Line C }
end.
LineOutput
Line A — writeln(x)
Line B — writeln(y)
Line C — writeln(p^)

Recall: p^ dereferences pointer p; @x gives the address of variable x.
